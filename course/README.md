# Complete AI Agent Course Page

This course explains the real project in `../study-agent/` from beginning to end.

Every lesson includes:

- What the concept is
- What job it performs
- A concrete analogy or example
- Exact code from the project
- A checkpoint before continuing

## Run the course page

```bash
python3 -m http.server 8080 --directory course
```

Open `http://localhost:8080`.

## Run the project

```bash
cd study-agent
npm install
npm test
npm start
```

Open `http://localhost:3000`.
