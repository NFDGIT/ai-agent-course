STEP 01 · 5 MIN

Understand what an AI agent is

WHAT IS IT?

An AI agent is an application where a model can choose actions, receive their results, and continue until it finishes a goal.

WHAT DOES IT DO?

It turns a one-response chatbot into a multi-step worker that can calculate, save, search, or call other software.

CONCRETE EXAMPLE

User: “I have 3 hours. Make a 25-minute study plan.”

  1. The model understands that calculation is required.
  2. It requests the calculator tool.
  3. Our JavaScript runs the tool and returns “7 sessions.”
  4. The model uses that result to write the plan.
Important: the model does not run JavaScript itself. It requests a tool; your application decides whether and how to execute it.

STEP 03 · 6 MIN

Build the API server

WHAT IS AN API?

An API is a defined way for two programs to communicate. Here, the browser sends an HTTP request to the Node.js server.

WHAT DOES THE SERVER DO?

It protects the API key, validates input, calls the agent, and returns JSON to the browser.

EVERYDAY ANALOGY

The browser is a restaurant table, the server is the waiter, and the agent is the kitchen. The waiter carries the request and result without exposing the kitchen’s private equipment.

study-agent/server.js · agent endpoint
app.post("/api/agent", async (request, response) => {
  const message = request.body?.message?.trim();

  if (!message) {
    response.status(400).json({ error: "message is required" });
    return;
  }

  try {
    const result = await runStudyAgent(message);
    response.json(result);
  } catch (error) {
    console.error(error);
    response.status(500).json({ error: error.message || "The agent failed" });
  }
});

1. app.post creates an endpoint that accepts data.

2. The server reads request.body.message.

3. Empty input returns a 400 error.

4. Valid input is passed to runStudyAgent.

5. The result becomes a JSON response.

STEP 05 · 5 MIN

Give the agent instructions

WHAT ARE INSTRUCTIONS?

Instructions are the agent’s job description: role, goal, behavioral rules, and boundaries.

WHAT DO THEY DO?

They turn a general model into a study-planning model that behaves consistently for this application.

EVERYDAY ANALOGY

A talented employee still needs a clear brief: “Teach beginners, use simple language, calculate before promising a schedule, and keep the result practical.”

study-agent/agent.js · instructions
const instructions = `
You are a beginner-friendly Study Planner Agent.

Your job is to turn a learning goal into a small, practical study plan.

Rules:
- Explain the plan in simple language.

STEP 06 · 9 MIN

Create tools: the agent’s actions

WHAT IS A TOOL?

A tool is a normal application function described to the model with a name, purpose, and argument schema.

WHAT DOES IT DO?

It performs deterministic work—such as calculation or saving data—that should not depend on generated text.

OUR TWO TOOLS

calculate_study_sessions turns hours into session counts. save_learning_goal stores the current learning goal.

Part A: describe the tool to the model

study-agent/tools.js · tool definition
{
  type: "function",
  name: "calculate_study_sessions",
  description: "Calculate how many complete focus sessions fit into the available study time.",
  strict: true,
  parameters: {
    type: "object",
    properties: {
      hours: {
        type: "number",
        description: "Total hours available for studying."
      },
      session_minutes: {
        type: "number",
        description: "Length of one focus session in minutes."
      }
    },
    required: ["hours", "session_minutes"],
    additionalProperties: false
  }
}

Part B: write the real JavaScript function

study-agent/tools.js · calculator implementation
export function calculateStudySessions({ hours, session_minutes: sessionMinutes }) {
  if (!Number.isFinite(hours) || hours <= 0) {
    throw new Error("hours must be a positive number");
  }

  if (!Number.isFinite(sessionMinutes) || sessionMinutes <= 0) {
    throw new Error("session_minutes must be a positive number");
  }

  const totalMinutes = Math.round(hours * 60);
  const sessions = Math.floor(totalMinutes / sessionMinutes);
  const unusedMinutes = totalMinutes - sessions * sessionMinutes;

  return {
    total_minutes: totalMinutes,
    sessions,
    session_minutes: sessionMinutes,
    unused_minutes: unusedMinutes,
  };
}
Schema versus function: the schema tells the model how to request the action. The JavaScript function actually performs it.
CHECKPOINT

STEP 07 · 10 MIN · MOST IMPORTANT

Build the agent loop

WHAT IS THE AGENT LOOP?

It is the application loop that connects model decisions, tool execution, observations, and the next model decision.

WHAT DOES IT DO?

It allows the task to continue across several actions instead of stopping after the first model response.

Ask model→Find tool calls→Run tools→Return results↺
study-agent/agent.js · agent loop
for (let step = 0; step < 6; step += 1) {
  addTrace(trace, "decision", `Model turn ${step + 1}`,
    "Ask the model for the next response or action.");

  const response = await client.responses.create({
    model,
    instructions,
    tools: toolDefinitions,
    input,
  });

  input.push(...response.output);
  const functionCalls = response.output.filter(
    (item) => item.type === "function_call");

  if (functionCalls.length === 0) {
    return {
      mode: "openai",
      answer: response.output_text,
      trace,
    };
  }

  for (const functionCall of functionCalls) {
    const argumentsObject = JSON.parse(functionCall.arguments);
    const result = await executeTool(
      functionCall.name, argumentsObject);

    input.push({
      type: "function_call_output",
      call_id: functionCall.call_id,
      output: JSON.stringify(result),
    });
  }
}

1. Ask the model what to do.

2. Keep the model’s output in the conversation.

3. Find all requested function calls.

4. If there are none, the agent is finished.

5. Otherwise, execute every requested tool.

6. Add each tool result back to input.

7. Repeat so the model can observe the result.

EVERYDAY ANALOGY

A GPS repeats the same loop: observe location → choose direction → act → observe the new location. Without the loop, it could give only one direction.

STEP 08 · 7 MIN

Connect the browser to the agent

WHAT IS FETCH?

fetch is the browser function used to send HTTP requests and receive responses.

WHAT DOES IT DO HERE?

It sends the textarea message to /api/agent, waits for JSON, then displays the trace and final answer.

try {

      providerAlias: providerSelect.value,

  modeBadge.textContent = data.mode;

}

STEP 10 · OPTIONAL PROVIDER UPGRADE

Discover providers and choose a model

WHAT IS A PROVIDER?

A provider is the service hosting one or more models. Its base URL tells the SDK where API requests should go.

WHAT DOES THE ALIAS DO?

The alias is a friendly local name—such as Local Ollama—so the UI does not need to display a long URL everywhere.

USER PROVIDES
Alias + base URL + optional key
→
SERVER DISCOVERS
GET {baseUrl}/models
study-agent/providers.js · model discovery
const modelResponse = await fetch(`${normalizedBaseUrl}/models`, {
  headers,
  signal: AbortSignal.timeout(12_000),

const payload = await modelResponse.json();
const models = extractModelIds(payload);

providers.set(normalizedAlias.toLowerCase(), {
  alias: normalizedAlias,
  baseUrl: normalizedBaseUrl,
  apiKey: apiKey.trim(),
  models,
  source: "custom",

const provider = getProvider(providerAlias);
const model = selectProviderModel(provider, requestedModel);

const client = new OpenAI({
  apiKey: provider.apiKey || "not-needed",
  baseURL: provider.baseUrl,
});
Security: the API key is submitted to your local server, kept only in memory, and removed from every provider object sent back to the browser.
COMPATIBILITY RULE

Loading the model list proves that /models works. Running this particular agent also requires the provider to implement OpenAI-compatible /responses requests and function calling.
